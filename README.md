# telegram-ai-assistant-n8n
AI-powered Telegram assistant built with n8n, OpenAI, Supabase (PostgreSQL), and Google Sheets knowledge base.
AI Telegram Assistant with Persistent Memory

An AI-powered Telegram assistant built with n8n, OpenAI, Supabase (PostgreSQL) and Google Sheets.

Features
🤖 AI-powered Telegram chatbot
🧠 Short-term conversation memory
💾 Long-term memory using PostgreSQL (Supabase)
📚 Knowledge base powered by Google Sheets
👤 Personalized responses
📝 Automatic conversation summaries
⚡ Built with n8n

Technologies
n8n
OpenAI API
Telegram Bot API
Supabase
PostgreSQL
Google Sheets
